# 素材记录

2026-11-07 使用内置图片生成工具，按已确认的像素桌面样稿生成。每张图的完整提示词保存在同名 `.prompt.txt` 文件。

| 文件 | 用途 | 网格 |
| --- | --- | --- |
| wallpaper.png | 雨夜桌面壁纸 | 整图 |
| cat.png | 自然猫形助手，蹲坐、眨眼、趴卧与仰望 | 2 × 2 |
| icons.png | 桌面与文件图标 | 4 × 3 |
| evidence.png | 场景与物件底图 | 4 × 3 |
| witnesses.png | 监控取证画面（红衣涂鸦离场、制服三条横杠与两把钥匙） | 2 × 1 |

`evidence.png` 仅是环境插画，不能单独作为可推断证据。证件、账单、监控记录、聊天和课程表必须由实际案卷数据制作可阅读的证据卡；关键信息不能由这张底图代替。没有通过证据与数据逐项核对的画面，不记为案件素材验收通过。

所有 UI 控件、文字、字段、数字及交互由代码实现。图片从源码导入，不依赖在线生成或远程 CDN。

## 简报语音

2026-11-08 使用 `node-edge-tts@1.2.12` 预生成十案简报，采用用户选定的“沉稳男声”：`zh-CN-YunjianNeural`，语速 `-8%`，音高 `-5Hz`，与①号试听一致。格式为 24 kHz、48 kbps 单声道 MP3。生成工具通过 `pnpm dlx` 临时运行，没有加入游戏依赖。

`briefings/case-1.mp3` 至 `case-10.mp3` 逐案对应完整的简报正文；原文与生成参数记录在 `briefings/manifest.json`。正文目前不随随机种子改变，证据中的随机值不包含在语音里。修改简报时须同步重新生成对应音频，内容测试会检查原文是否一致。

音频从源码导入，随整站与独立 HTML 打包；游玩时不调用在线语音服务，也不依赖设备安装的中文朗读声音。
