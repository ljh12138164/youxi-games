# 文字世界

橘白小猫的规则推箱子。用户已确认 A「纸上规则」美术方向：奶油纸面、深绿印章字、赤陶色性质词块和橘白小猫。

封面原图：[方形主封面](art/cover-square-v1.png)、[横版展示封面](art/cover-landscape-v1.png)。尺寸与提示词见 [封面说明](art/README.md)。

## 玩法

棋盘中的文字可以推动。三个连续的字块从左到右、或从上到下组成「物体 是 性质」后，立即改变世界。

- 你：获得控制权，可以同时控制多个对象。
- 推：对象能被推动，连续方块一起推；推不动时整次推动不生效。
- 挡：阻止通行；有「推」时可被推走。
- 赢：可控制对象进入这个对象所在格时通关。
- 沉：对象与其他物体接触后一起消失；可以牺牲石头或文字清出通道。小猫沉没后可撤销恢复。

文字始终可推动；未被赋予「推」「挡」的物体可穿过。棋盘边界不可越过。移动使用移动前的规则，移动结束后重新读规则和判断胜利。包含五种名词和五种性质，不实现文字变形、否定、与运算等其他作品的扩展规则。

十二个入门关按移动、推石头、拆规则、补规则、多对象控制、改变终点、推动墙、复用词块、竖向规则、组合条件、交叉规则、控制权接力递进。另有六个挑战关，组合水的沉没、石头和文字的牺牲、跨岸运输、修改水的性质、控制权移交和重新定义终点。

选关页分为「入门」「挑战」，挑战第一关可以直接进入，不必重玩教学。完成原十二关的旧存档自动解锁新篇章入口，原有棋盘和最佳步数保留。关卡均为本项目原创；可解路径保存在 `src/levels.ts`，单测和两端实际输入回归核验路径。这些路径不是最短步数或真人难度的证明。

## 操作

手机／平板支持滑动棋盘、点按方向按钮及按住连续移动。手机竖屏始终使用十字方向盘，紧凑布局的方向按钮为 52 CSS 像素；上下同列、左右同行，按住时高亮。撤销、重来、提示和设置独立放在左侧，不与方向键混成一排。横屏用棋盘与操作区并排布局，方向按钮至少 44 CSS 像素。

桌面使用方向键或 WASD，Z 撤销，R 重来，Esc 暂停；也可鼠标操作。通关后 Esc 不改变暂停状态。

走不动时会说明阻挡原因，不计步；改写规则时会标出具体生效或失效的句子。撤销有回退过渡，重来也可以撤销返回原局面。设置中可关闭动态效果；网页同时尊重系统减少动画偏好。

标题页、选关、关卡解锁、最佳步数、局内提示、撤销重来、通关与全关完成界面、音效设置均可用。进度每步自动保存，最多恢复最近 64 步撤销记录；本次会话保留最多 256 步。撤销通关不会收回已经解锁的关卡。

## 开发与构建

```powershell
pnpm dev --host 127.0.0.1 --port 5174
pnpm run build:game -- rule-kitten-h5
pnpm run build:kitten:douyin
pnpm run test:kitten:canvas
```

- 浏览器：`http://127.0.0.1:5174/games/rule-kitten-h5/`
- 独立 H5：`dist/games/rule-kitten-h5/index.html`，图片内联，可离线打开。
- 抖音：导入 `dist/douyin/rule-kitten-h5/`，类型选择小游戏。
- 合法应用 AppID 通过 `RULE_KITTEN_DOUYIN_APP_ID` 环境变量提供。本地包不伪造 AppID；扫码预览、真机和提审需要真实应用配置。

两端共享规则、关卡、Canvas 界面、动画和进度校验。平台入口仅负责输入、视口、安全区、图片加载、存储、音效和前后台生命周期。抖音包不包含 DOM、Web Storage、React 或游隙网页适配器依赖，所有资源本地打包。

浏览器存档键：`youxi:rule-kitten-h5:save:v1`；抖音存档键：`youxi:rule-kitten-h5:douyin:save:v1`。存档互不覆盖，不自动跨平台同步。
