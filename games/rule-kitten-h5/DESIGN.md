# 纸上规则

用户确认的美术方向为 A，主角为橘白小猫。完整界面遵循纸上棋盘的视觉，深绿字、奶油纸、赤陶色印章；没有沿用既有游戏的像素图集。

| Token | Value | 用途 |
|---|---|---|
| paper | `#f7edda` | 主纸面 |
| ink | `#204d43` | 正文、轮廓、主要按钮 |
| muted | `#657265` | 次要说明 |
| property | `#be6040` | 性质字块、关卡标签 |
| grid | `#b3baa0` | 格线与分隔线 |
| white | `#fff9ed` | 深色块上的文字 |

角色、石箱、墙、旗子与空白词块来自本游戏的生成图集 `src/assets/atlas-paper-v1.png`。文字由 Canvas 实时绘制，不把规则烘焙进图片。标题及字块优先本机楷体，其他文字用系统无衬线字体，不依赖远程字体。

桌面宽屏为棋盘左、规则与控制右；常规手机竖屏为棋盘上、控制下。可用高度低于 760px 或宽度小于 360px 时，使用实际 CSS 尺寸重排，方向盘为 52px 按键、6px 间隙的十字布局。所有手机竖屏保持上／下同列、左／右同行，禁止重新压成一排箭头。撤销、重来与其他辅助操作在方向盘左侧分组；紧凑横屏按键至少 44px。按住方向键时深绿高亮，松开或取消后结束连走。紧凑竖屏的长提示使用可收起说明层。浏览器与抖音分别读取实际安全区。

挑战篇的水格用浅蓝绿色纸面与深绿波纹区分；规则词「沉」沿用赤陶色性质词。选关按入门／挑战两篇分页，不将十八关挤入同一屏。

移动有短距离平滑过渡，推不动不计步，改规则有文字提醒；失去控制时明确提示撤销。暂停原因相互独立。移动／改规则／通关有短音效，静音可保存，后台与平台临时静音不覆盖用户偏好。

交互反馈遵循 interaction-design：按键反馈约 120ms，走不动时角色轻触回弹约 150ms，并显示边界／阻挡原因；反馈不增加步数。规则改变时明确列出新生效／失效的句子，相关字块以实线／虚线短暂标记，避免只靠颜色表达。
移动和撤销采用约 120ms 的过渡；连按时从当前画面位置接续，不锁住输入。重来保留可撤销的原局面并明确提示恢复方式。
桌面按钮提供悬停与手形指针，快速滑动以最终触点收尾。网页尊重系统 prefers-reduced-motion，并监听实时变化；游戏设置也可关闭动态效果，存档保留用户选择。减少动态时仍保留文字与静态边框提示，抖音使用相同开关。
