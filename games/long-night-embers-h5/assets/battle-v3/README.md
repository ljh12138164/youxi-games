# 战斗素材 v3

2026-11-01：按用户截图指定的敌人与首领、拾取物、技能弹体区域优化，延续已确认骑士/人物的精细像素风。内置 imagegen 原创生成，未使用第三方游戏素材。

覆盖 16 种敌人与首领、13 种常规拾取物和 8 类弹体。原始图集经透明通道检查后，按格间透明间隙裁切并缩放到带留白的 192px 敌人、128px 拾取物/弹体画布。运行时保持原有 44/56px 敌人画布、32px 拾取物、48px 弹体，采用 nearest 采样。源图集标识和完整生成提示见本目录 JSON/TXT。

实现位于 `src/render/approvedArt.ts` 和 `pixelArt.ts`。冻结通过半透明冰蓝色覆盖，受击闪白保留原图 alpha；两相位起伏保留，未引入完整逐帧攻击/步行动画。8 类弹体统一朝右，由现有速度向量旋转；没有将菜单法杖或怀表作为弹体发射。其余武器继续使用既有独立效果或装备纹理。

不修改敌人数据、血量、碰撞、掉落、攻击规则与存档。已有近战线段和激光等特效保持原实现。

验证：`pnpm test`、typecheck/lint、整站和独立构建；`tests/battle-art.browser.mjs` 检查素材覆盖、透明轮廓、冻结和闪白、弹体横向形态及实际 Pixi 场景；既有素材/渲染浏览器测试通过。图片验收：`reports/battle-art-v3.png`、`reports/battle-art-v3-in-game.png`。独立产物平台自测使用仓库工具，未进行线上发布。
