# 精细像素素材 v2

2026-11-01。用户已授权沿用确认骑士与四角色预览板风格继续实现，无需逐张确认。

本批补齐 12 名人物、20 件基础武器、21 件进化武器、22 件被动道具。与 v1 合计覆盖全部 17 名非 DLC 角色、47 件非 DLC 武器和 23 件非 DLC 被动。头像、图鉴、菜单、拾取物和适用弹体复用对应素材；魔法飞弹等继续使用独立战斗特效，不直接发射菜单图标。

素材为内置 imagegen 原创生成，以 v1 确认板作风格参考，统一成人比例、精细像素轮廓、暗钢/旧黄铜/皮革材质与左上光照。人物保留各自职业、配色、手持装备和轮廓，没有使用第三方游戏资源。生成提示及源文件标识见本目录的 JSON/TXT。

人物缩至 256px、装备缩至 128px 透明画布并保留四周留白。裁切使用透明通道定位图集间隔与主体边界，nearest 缩放；实际运行时战场人物为 64px 画布，菜单头像为 68px，物品为 48px。浏览器白底合成与游戏暗底显示均已检查。部分原始文件在透明像素中保留了 RGB 背景色，部分查看器会错误显示它；实际 alpha 合成正常。

本批未更改玩法、解锁条件、人物初始装备和存档标识；移动仍为轻微起伏，未新增逐帧迈腿、挥剑动画。

验证：`pnpm test`、类型检查、lint、整站/独立构建，`tests/assets.browser.mjs` 的全量素材覆盖、透明边界、17 名角色存档进入战场与暂停，以及 `tests/render-regressions.browser.mjs`。浏览器验收截图保存在本地 `reports/`。平台检查使用仓库工具，不是官方认证，未进行线上发布。
