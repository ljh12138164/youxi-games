| 问题 | 原因与修复 |
| --- | --- |
| 弹体出现黑色方块/菱形 | 战场复用了带槽位底色的菜单图标；战场纹理改为透明，菜单保留底色。 |

| 鞭子误伤上方和背后的敌人 | 水平线特效却使用大圆碰撞；改为与可见线段一致的胶囊判定，前向鞭击从玩家位置延伸。 |
| 激光远端无伤害、背后却受伤 | 零速激光落入随机弹体分支，判定圆停在角色身上；改为按施放时朝向创建水平光束，显示和伤害共享端点，转身不重定向旧光束。 |
| 圣经伤害覆盖整个轨道内部 | 轨道半径同时作为单本书的碰撞半径；分离轨道距离和书本碰撞半径。 |
| 清屏后零血敌人仍存在 | 只把 hp 置零，没有进入死亡结算；在区域伤害、弹体和接触判定之前统一结算，保留死神免疫。最近目标搜索也排除零血目标。 |
| 弹体卡边界连续反弹 | 弹体越界后仍留在界外，每帧重复翻转速度；回到边界，并且只对朝外运动反弹。 |
| 宽屏右侧物体提前消失 | 相机使用实际画布宽度，裁剪和场景装饰仍使用固定 960；统一使用当前逻辑画布尺寸。 |
