# 《永夜余烬》生存弹幕品类玩法机制与设计规范

更新日期：2026-10-31  
关联规划：[ROADMAP.md](./ROADMAP.md)  
项目标识：`long-night-embers-h5`。本文件为内部玩法与工程设计规范，不随前端产物打包分发。

## 规范状态

- `已实现`：代码与逻辑已在当前版本落地，通过自动化测试覆盖。
- `待扩展`：已规划系统，等待后续迭代版本实现。
- `H5 适配`：根据 Web 平台特性量身制定的交互、渲染或存档策略。

设计原则：独立自研玩法与资产；核心参数以真实平衡测试与运行表现为准，不依赖外部未经验证的经验值。

## 玩法与系统边界

| ID | 模块 | 规范范围 / 设计约束 |
| --- | --- | --- |

## 内容台账要求

代码台账维护于 `games/long-night-embers-h5/src/content/ledger.ts`。每项内容必须具备清晰的定义：`id`、`name`、`category`、`status`、数值属性及行为类型，并由 `validateContentIntegrity()` 自动化校验。

统计与管理应分类明确：
1. 初始及解锁角色
2. 基础武器、进阶武器及合成衍生形态
3. 被动物品与属性道具
4. 地图场景、障碍几何与动态刷怪波次
5. 怪物属性、Boss 阶段与掉落配置
6. 永久强化项与价格成长公式
7. 局内奥秘牌与特殊玩法规则

## 平台与架构设计

| ID | 架构选型 | 说明 |
| --- | --- | --- |
| H01 | 单人桌面优先 | 首版优先桌面鼠标/键盘体验，布局契合宽屏与全屏沉浸感。 |
| H02 | 纯前端状态驱动 | 核心逻辑与渲染解耦，核心物理与数值不依赖 DOM，便于测试。 |
| H03 | 焦点安全控制 | 失去焦点自动暂停，平台遮盖层展开时立即静音并冻结局内时钟。 |
| H04 | 本地持久化 | 基于 Web Storage 独立命名空间，避免不同游戏或不同环境数据串扰。 |
| H05 | 原创像素视觉与合成音效 | 采用纯自研像素绘制管线与 Web Audio 程序合成音效，杜绝版权隐患。 |
| H06 | 轻量级单包分发 | 零网络加载依赖，构建为自包含单文件，确保秒开与离线鲁棒性。 |
