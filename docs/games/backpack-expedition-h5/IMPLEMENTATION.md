## 已实现

- 难度可选：轻松 / 标准 / 挑战，新局默认标准。初始生命分别为 40 / 34 / 30，金币 26 / 20 / 16，战后恢复 4 / 2 / 0；挑战取消濒死救援。三档普通攻击倍率按层分别为 [0.75,0.85,0.95] / [0.9,1,1.1] / [1.05,1.2,1.35]。轻松额外获得一瓶药剂，三档均保留 24 格背包与保底掉落。难度随局保存，切换需确认重开，无字段旧档沿用轻松规则。

- 三层森林、每层六站、分叉路线、9 类普通敌人、3 类精英、3 个层末守卫、6 个事件。

- 回合制战斗、敌人意图、每件主动装备每回合一次、商店买卖、营地恢复和成长、战利品放弃确认、正常胜利与失败。
- 本地独立存档、行动后保存、上一份备份、JSON 导入导出、存档结构与占格校验、旧窗口版本变化拒绝覆盖。浏览器 Web Storage 不是跨窗口数据库事务，严格并发原子保护仍需补充。
- 图鉴发现跨重新开局保留；暂停、平台侧栏与防 Boss 遮盖、隐藏暂停、中央静音、音效和键盘快捷键。

## 手机操作与体验更新（2026-11-02）

- 手机点击选择物品、点击格子放置，旋转按钮与键盘 R 共用逻辑；触摸不触发鼠标拖放，背包和地上物品允许纵向滑动页面。调整 320–840px 布局、首页、双敌人站位、菜单触点、存档弹窗及安全区。桌面仍保留拖放。
- 背包前增加快捷目标，先选武器，再点击目标按钮或按数字 1/2 攻击；仍可直接点战场敌人。快捷目标显示敌人生命与护盾，使用后、能量不足、死亡及暂停时按原规则限制攻击。

- 新增可选存档字段 `stepsPerFloor:8` 与 `seenEvents`，读档严格校验；无字段旧档继续每层 6 站，原存档键与旧事件索引保持有效。

## 后续范围

2026-11-03 交换修正：此前只支持一个目标并固定回填到源物品左上角，导致四格物品仅挪一格也可能误判失败。现统一用 `swapPlan` 搜索所有被覆盖物品的合法位置，优先使用源物品真正腾出的格子，再使用其他空位，保持目标物品方向、不移动无关装备。多目标通过组合搜索后一起提交，任意一件无法安置则整体拒绝；从地上换入时全部被覆盖物品移到地上。预览高亮所有交换目标及回填格子，显示交换件数。新增四格左移一格、四件小物品一起回填和部分可放但整体失败的测试；66 项单测、四组相关浏览器回归、类型检查、整站及独立构建通过。截图 `swap-shift.png`、`swap-multiple.png`。本轮未提交、推送或发布。

当前使用 12 类物品外形与 3 类敌人外形，内容变体共享图像。独立变体、逐帧攻击/受击动作、更多音频和真人长局平衡留在 M4；不把当前图集算作全部独立正式素材。
