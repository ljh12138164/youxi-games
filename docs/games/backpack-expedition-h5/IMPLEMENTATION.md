## 已实现

- 难度可选：轻松 / 标准 / 挑战，新局默认标准。初始生命分别为 40 / 34 / 30，金币 26 / 20 / 16，战后恢复 4 / 2 / 0；挑战取消濒死救援。三档普通攻击倍率按层分别为 [0.75,0.85,0.95] / [0.9,1,1.1] / [1.05,1.2,1.35]。轻松额外获得一瓶药剂，三档均保留 24 格背包与保底掉落。难度随局保存，切换需确认重开，无字段旧档沿用轻松规则。
- 拖拽保留抓取格及旋转后的抓取位置，背包外不吸附、不显示物品预览，松手取消；明确的“放到地上”区域允许临时腾位并取回。背包和战利品都能单件确认丢弃，最后一件武器受保护。
- 三层森林、每层六站、分叉路线、9 类普通敌人、3 类精英、3 个层末守卫、6 个事件。
- 40 件有独立 ID 与规则的物品，矩形和 L 形占格，四方向旋转、拖动和点击放置、非法回退、相邻扩容。
- 近战相邻增伤、弓的同行加成、盾与棘戒反击三类构筑规则；另有中毒、护甲、能量与消耗品。
- 回合制战斗、敌人意图、每件主动装备每回合一次、商店买卖、营地恢复和成长、战利品放弃确认、正常胜利与失败。
- 本地独立存档、行动后保存、上一份备份、JSON 导入导出、存档结构与占格校验、旧窗口版本变化拒绝覆盖。浏览器 Web Storage 不是跨窗口数据库事务，严格并发原子保护仍需补充。
- 图鉴发现跨重新开局保留；暂停、平台侧栏与防 Boss 遮盖、隐藏暂停、中央静音、音效和键盘快捷键。
- 原创生成的角色/物品图集及森林背景，中文文案按 humanizer-zh 调整；素材、生成提示词与来源有记录。
