## 1. 目标与范围

将桌面卡牌堆叠生存建造玩法实现为单机单文件 HTML5 游戏。

| 维度 | 目标定义 |
| --- | --- |
| 交付形态 | 纯前端单文件（SPA，HTML/CSS/JS 内联，单包 `< 2 MiB`） |
| 运行环境 | 现代桌面浏览器，离线可用，不依赖外部服务器或自建后端 |
| 首发设备 | 电脑浏览器，键鼠操作；后续按需扩展移动触控支持 |
| 渲染技术 | React + DOM/CSS 卡牌布局；结合纯代码程序化样式 |
| 核心规则 | 纯 TypeScript 领域模型，状态机与表现层严格解耦 |
| 存档方案 | 本地多槽位持久化、自动保存、备份防坏档与导入导出 |
| 平台接入 | 严格遵循 Scalia 游戏容器规范（生命周期、静音与全屏） |

### 1.1 内容范围定义

本作聚焦于核心陆地经营与离岛远航探险两大篇章，包含完整的人口繁衍、工具制作、建筑搭建、农耕畜牧、卡包交易、外敌防御与 Boss 终局挑战。

1. 包含核心可玩内容集（363 项功能卡牌、94 条配方、7 类卡包、15 项核心引导任务）。
2. 不引入未经验证的复杂网络联机或依赖特定商业引擎的私有格式。
3. 保持纯粹的单机桌面策略节奏，不增加破坏平衡的内购数值与强制广告。

## 2. 设计基线与交付口径

1. **确定性状态机**：卡牌堆叠、配方匹配、倒计时结算由确定性事务驱动，状态转移可复现。
2. **内容台账分母**：以 `games/card-realms-h5/src/content/ledger.ts` 登记的完整台账为准，逐项实现并经过自动化单元测试。
3. **无外部依赖**：视觉全部通过 CSS 卡牌层叠样式呈现，音效由 Web Audio 程序合成，无私有外部素材引入。

---

## 3. 核心机制模块规划

### 3.1 桌面与卡牌交互

- 响应式自适应桌面，支持滚轮平滑缩放与按住中键/拖拽桌面视口平移。
- 鼠标拖拽：支持单卡拖动、整堆批量拖动（Shift / 快速双击）；智能吸附与非法碰撞弹性回退。
- 卡牌层叠：被堆叠卡牌自动排列展示下半部标题，清晰显示当前堆叠层级与总高度。

### 3.2 生产与配方合成

- 堆叠触发配方匹配（如：村民 + 树木 = 采集木材；村民 + 木材 + 石头 = 简易工具）。
- 生产状态机：显示实时圆形/条形进度指示器；中途移除参与者自动打断并根据规则重置或保留进度。
- 多输出与废料管理：生产完成后产物平铺到周围最近空位，防止卡牌互相重叠卡死。

### 3.3 经济与卡包商店

- 独立金币机制：小钱袋与金币箱存储上限；交易时支持零钱自动合并与找零。
- 卡包商店：消耗金币采购基础包、农耕包、建造包、探险包等；开包具备翻牌散落物理动效。
- 出售机制：将闲置卡牌拖拽至钱箱或出售区即可即时回收金币。

### 3.4 月末结算与生存压力

- 月度时间推进：支持 90s / 120s / 200s 可选月长，并提供一键空格暂停与倍速切换。
- 食物与饥荒结算：月末遍历全场人口并扣除对应食物点数；食物不足时产生饥荒减员预警与损失。
- 人口繁衍：房屋建筑中放置两名村民并消耗食物可诞生新生儿。

### 3.5 战斗与防御

- 敌对生物遭遇：探险或周期性事件刷出哥布林、狼群等敌对卡牌。
- 遭遇战机制：战斗卡牌相遇时锁定并展开自动回合制交火，展示血量变化、击退效果与胜利掉落。
- 防御工事与民兵：配置长矛、剑盾转职战斗人员，搭建围墙与哨塔减缓敌人推进。

### 3.6 本地存档与健壮性

- 槽位隔离：提供 3 个独立游戏存档槽位，支持独立备份与命名。
- 容错保护：关键状态写入前后校验 CRC/签名，意外退出时自动保留前序快照；提供 JSON 导入导出。
