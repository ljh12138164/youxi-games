# 《卡牌领地》卡牌堆叠生存建造玩法机制与设计规范

更新日期：2026-10-31  
关联规划：[ROADMAP.md](./ROADMAP.md)  
项目标识：`card-realms-h5`。本文件为内部玩法与工程设计规范，不随前端产物打包分发。

## 规范状态

- `已实现`：代码与逻辑已在当前版本落地，通过自动化测试覆盖。
- `待扩展`：已规划系统，等待后续迭代版本实现。
- `H5 适配`：根据 Web 平台特性量身制定的交互、渲染或存档策略。

设计原则：独立自研卡牌堆叠生存机制与纯代码程序化渲染；核心规则基于真实交互测试与状态机校验。

## 玩法与系统边界

| ID | 模块 | 规范范围 / 设计约束 |
| --- | --- | --- |

## 内容台账要求

代码台账维护于 `games/card-realms-h5/src/content/ledger.ts`。每项卡牌必须具备清晰的定义：`id`、`name`、`category`、`cost`、`foodValue` 及交互能力，并由自动化单元测试校验。

统计与管理应分类明确：
1. 人员与职业（村民、农夫、民兵、工匠等）
2. 基础资源与采集节点（木材、石头、浆果、铁矿、树木、岩石等）
3. 生产建筑与合成设施（篝火、棚屋、锯木厂、采石场、农田等）
4. 食物与烹饪配方（生熟肉食、浆果、炖菜等）
5. 敌人与战斗实体（哥布林、骷髅、野兽、Boss等）
6. 卡包商店池与抽卡权重
7. 成就引导与主线任务链

## 核心规则与系统验收

| ID | 系统模块 | 验收标准 | 阶段门槛 |
| --- | --- | --- | --- |
| R01 | 基础桌面与视口 | 响应式自适应桌面、平滑滚轮缩放、视口拖动、卡牌自适应排列 | M1 |
| R02 | 拖动与堆叠吸附 | 单卡拖动、整堆批量移动、吸附距离判定、非法重叠排斥回弹 | M1 |
| R03 | 工作进度状态机 | 堆叠触发配方合成进度、进度条实时渲染、打断与恢复处理 | M2 |
| R04 | 游戏时钟与暂停 | 暂停时冻结生产倒计时与怪物行动；支持标准月长与调速设置 | M1/M2 |
| R05 | 基础采集与消耗 | 实体卡牌堆叠在资源节点上按时产出原料，达到耐久上限后节点耗尽 | M2 |
| R06 | 配方识别系统 | 多重集合格匹配、支持多对一/多对多合成规则，成功后生成产物与返还母卡 | M2 |
| R07 | 卡包开箱机制 | 消耗金币购买卡包、开包动画、权重抽取随机掉落、桌面空位散落 | M2 |
| R08 | 金币与交易 | 独立钱箱存储、出售卡牌实时获利、购买物品优先扣除零散金币 | M2 |
| R09 | 月末饥荒结算 | 倒计时结束遍历全场人口并扣除对应数量食物，食物不足触发饥荒伤亡 | M2 |
| R10 | 即时战斗系统 | 敌对生物遭遇卡牌并自动交火、回合攻击间隔、受击闪烁与胜负掉落 | M2/M5 |
| R11 | 本地存档管理 | 多槽位存档存储、自动保存、存档导出与导入完整性校验 | M3/M6 |
| R12 | 平台生命周期 | 页面失焦自动暂停游戏与静音，焦点恢复时正确清理事件状态 | M1/M6 |
