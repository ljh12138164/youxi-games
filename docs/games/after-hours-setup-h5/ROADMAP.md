# 《装机夜班》H5 设计与开发路线图

《装机夜班》（项目标识 `after-hours-setup-h5`）是一款简体中文单人网页桌面解谜游戏。玩家扮演夜班计算机维修员，在复古邮件客户端 **Outhook Express** 中接收十六位委托人的装机求助，逐一启动风格复古的软件安装向导，识破隐藏在按钮、协议条款、加载界面与弹窗中的捆绑陷阱，完成「0 捆绑」纯净安装，赚取酬劳并结清 `$7,000.00` 店铺尾款。

## 1. 核心体验与交互流程

1. **Outhook Express 桌面邮箱**：游戏启动即进入全屏 Windows 11 Fluent 风格桌面邮件客户端，包含顶部菜单栏（文件、编辑、视图、工具、信息、帮助）、命令工具栏（删除、恢复、删除已读、设置、指南、音乐、暂停）、左侧文件夹与邮件树（收件箱、回收站）及右侧卡片阅读区；首次进入提供 `driver.js` 驱动的 7 步互动新手指引。
2. **邮件状态区分**：收件箱内未读邮件及尚未领取酬劳/待缴账单的邮件以红色高亮显示；未结清酬劳的邮件受保护不可删除；已读邮件可移入回收站并支持随时恢复。
3. **点击附件直达安装向导**：点击求助邮件正文下方的 `.exe` 安装包按钮，画面切换至深蓝 Cobalt Bloom 背景与居中 Windows 11 安装向导弹窗，包含经典左侧装机插画与右侧多阶段向导界面。
4. **安全检测与返工机制**：每次走到「完成」页并提交后，系统弹出「流氓软件安全检测」窗口：
   - 若检测到 `>= 1` 个暗中捆绑项或未满足纯净安装条件，会明确给出异常项数；从第二次失败起开放「查看排查线索」按钮，并支持直接「重新安装排查」或「返回邮箱」。
   - 若检测到 `0` 个流氓捆绑软件，即返回 Outhook Express 收到委托人发来的红色回信与 `$金额` 酬劳按钮；点击领取后右下角状态栏余额滚动增长，同时自动投递后续委托邮件。
5. **结清尾款与结局**：累计赚够 `$7,000.00` 后，在「店铺宽带与主机尾款结算单」中点击支付，进入夜班收工结业画面并可随时重玩任意安装程序。

## 3. 视觉、音频与跨端适配

- **风格体系**：采用 Windows 11 Fluent 桌面应用视觉风格，邮箱端以高辨识度石板灰 `1px` 边框与 Mica 桌面底色区分命令条、左导航蓝条指示器（`#0067C0`）与红悬停关闭按钮（`#C42B1C`）；安装向导采用深蓝渐变聚焦底景、圆角弹窗、自定义矢量图标与等距装机插画。全部样式基于仓库级 Tailwind CSS 4（`@shared/styles/tailwind.css` + `@source './'`）与游戏内 CSS 完成，零外部字体或在线图片依赖。
- **音频与音乐**：使用 Web Audio API 实时合成点击、新邮件提示、领取酬劳、警报与通关音效，并随包内置 4 首 CC0 / CC BY 3.0 真钢琴录音 MP3 背景音乐，支持设置切歌并严格同步用户静音、平台临时静音及暂停状态。
- **桌面与移动适配**：
  - 桌面端保持左右分栏文件夹树 + 阅读区，支持键盘 `Esc` 暂停、右键菜单及快捷键（如 `Shift+F10`）。
  - 360px 窄屏自动切换上下堆叠布局、放大触控热区至 44px 以上，且对「点击左侧插画」「呼出右键菜单」关卡提供移动端等价触控入口，确保零横向滚动溢出。

## 4. 存档、平台接入与工程验证

- **存档与恢复**：使用 `localStorage`（键名 `after-hours-setup-h5/v2`）持久化余额、已解锁/已读/已删除/已领取邮件、已通关安装包、失败尝试次数、设置项及结局状态；支持损坏存档备份重置与进度彻底重置。
- **平台适配**：通过 `@shared/platform` 接入 `ready()`、侧栏/Boss 暂停与临时静音回调；提供 `tests/platform-driver.mjs` 驱动，可由 `scripts/platform-selftest.mjs` 验证就绪、暂停/恢复和音频静默状态。
- **验证基线**：
  - 单元测试：`games/after-hours-setup-h5/tests/game.test.ts` 验证全部 16 套安装包的默认拦截与通关判定、反话校验、邮件保护与 `$7,000` 通关账单链路。
  - 浏览器端到端：`games/after-hours-setup-h5/tests/gameplay.browser.mjs` 在桌面与 360px 触控视口实测全流程与刷新读档。
  - 构建产物：`pnpm run build:game -- after-hours-setup-h5` 生成单文件 `dist/games/after-hours-setup-h5/index.html`。
