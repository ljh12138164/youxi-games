# 共享代码边界

当前包含：

- `@shared/styles/base.css`：可选的公共基础样式。
- `@shared/platform`：游隙官方 `youxi-game-v1.js` 运行时协议适配器及其 TypeScript 薄封装（来源固定 `https://scalia.ltd`，支持顶层直开降级、身份通知、侧栏/防 Boss 状态、同步临时静音回执与 `ready()`）。

共享模块不能反向依赖任何具体游戏；不要提前加入通用游戏引擎、全局状态仓库或抽象插件系统。

每款游戏的状态、规则、内容与资源属于自己的 `games/<slug>/`。不同游戏不互相导入业务代码。真正重复的功能出现后，再提取到这里。
